- [Docker](https://docs.docker.com/get-docker/) instalado

### Subindo o ambiente

```bash
# 1. Clone o repositório

cd ds881-curriculo-20246038

# 2. Suba o container
docker compose up --build

# 3. Acesse no navegador
# http://localhost:8080
